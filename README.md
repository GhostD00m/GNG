Список литературы и источники

В ходе подготовки доклада и реализации эксперимента использовались следующие материалы:

### Основополагающие статьи (теория)
1. **Fritzke, B. (1995).** *A Growing Neural Gas Network Learns Topologies.* — Оригинальная статья, в которой представлен алгоритм GNG.
   - [Ссылка на PDF (NeurIPS)](https://proceedings.neurips.cc/paper/1994/file/d56b9fc4b0f1be8871f5e1c40c0067e7-Paper.pdf)
2. **Martinetz, T. M., & Schulten, K. J. (1991, 1994).** *Some Competitive Learning Methods / Topology Representing Networks.* — Базовые работы по Neural Gas и Competitive Hebbian Learning (CHL), на которых основан GNG.
   - [Ссылка на PDF](https://vision.unipv.it/IA2/Some%20Competitive%20Learning%20Methods.pdf)
3. **Fritzke, B. (1997).** *A Growing Neural Gas Network with Utility (GNG-U).* — Модификация для работы с нестационарными потоками данных (решает проблему «мертвых» нейронов).
   - [Ссылка на PDF](https://demogng.de/papers/utility.pdf)

### Демонстрации и дополнительные материалы
4. **Интерактивная демонстрация алгоритма GNG** (визуализация 3D/2D, настройка параметров в реальном времени).
   - [Ссылка на DemoGNG.js](https://www.demogng.de/js/demogng.html?_3DV)
5. **Статья на Habr** (обзор и практические аспекты GNG).
   - [Ссылка на Habr](https://habr.com/ru/articles/340360/)
